# Analyzer

**Analyzer** — система сверки товарных каталогов: сравнение ассортимента и цен
между поставщиками (бренды-производители) и интернет-магазином. Состоит из
двух связанных компонентов, которые общаются **только через общую базу данных**:

1. **Парсер на Python** (`scripts/analyzer.py`) — загружает фиды поставщиков
   (XML/YML) и магазина (JSON), сравнивает товары по SKU и пишет результаты в БД.
2. **Веб-интерфейс на Laravel** (этот репозиторий) — отображает результаты:
   дашборд с графиками, таблицы с фильтрацией/сортировкой, экспорт в XLSX.

> Веб-приложение работает с данными **только на чтение** — оно ничего не пишет в
> бизнес-таблицы, все данные готовит Python-скрипт по расписанию.

---

## Возможности

- **Дашборд** — ключевые метрики (количество товаров, расхождения цен, наличие)
  и интерактивные графики (Chart.js): распределение по брендам и сводная
  диаграмма по статусам товаров.
- **Пять разделов данных**, каждый со своей таблицей:
  - **Товары поставщика** (`suppliers`) — полный каталог производителей с
    характеристиками, изображениями, ценами. Есть карточка товара (`show`).
  - **Есть в сайте** (`availables`) — товары, что и в магазине, и у поставщика,
    с прямым сравнением цен (`больше` / `меньше` / равно).
  - **Нет у производителя** (`unavailables`) — товары магазина, которых нет у
    поставщика.
  - **Нет в магазине** (`undiscovereds`) — товары поставщика, отсутствующие в
    магазине (потенциальные новинки ассортимента).
  - **Комплекты** (`kits`) — расчёт суммарной стоимости компонентов комплекта у
    поставщика и сравнение с ценой комплекта в магазине.
- **Фильтрация** по ключевым полям (название, SKU, бренд, категория, доступность,
  статус цены и т.д.).
- **Сортировка** по столбцам (строгий whitelist разрешённых колонок).
- **Пагинация** по 50 строк с сохранением параметров фильтра в строке запроса.
- **Экспорт в Excel (.xlsx)** текущей выборки с учётом применённых фильтров.
- **Авторизация** (Laravel Breeze), тёмная/светлая тема, адаптивная вёрстка.

## Технологический стек

| Слой | Технология |
|---|---|
| Бэкенд | Laravel 13, PHP 8.3 |
| Авторизация | Laravel Breeze (Blade) |
| Фронтенд | Vite, Tailwind CSS, Alpine.js |
| Графики | Chart.js |
| Экспорт | maatwebsite/excel (XLSX) |
| База данных | MySQL 8.0 / MariaDB 10.x |
| Сборщик данных | Python 3.12 (`requests`, `PyMySQL`) |
| Веб-сервер (прод) | Nginx + PHP-FPM (LEMP на Ubuntu) |

## Быстрый старт (локальная разработка)

```bash
# 1. Зависимости PHP и JS
composer install
npm install

# 2. Конфигурация окружения
cp .env.example .env
php artisan key:generate

# 3. Настройте подключение к MySQL в .env (БД analyzer), затем миграции
php artisan migrate

# 4. Сборка фронтенда
npm run build      # продакшн-сборка
# или
npm run dev        # режим разработки с горячей перезагрузкой

# 5. Локальный сервер
php artisan serve
```

После запуска откройте `http://localhost:8000` — произойдёт редирект на
`/login`. Для создания первого пользователя перейдите на `/register`.

> Подробное руководство по локальной разработке см. в
> [`docs/WEB-INTERFACE.md`](docs/WEB-INTERFACE.md#локальная-разработка).

## Где взять данные?

Данные в бизнес-таблицы (`suppliers`, `availables`, ...) загружает
Python-скрипт. Чтобы дашборд и таблицы не были пустыми, запустите парсер:

```bash
python3 scripts/analyzer.py
```

Полное описание работы парсера, источников данных и расписания — в
[`scripts/README.md`](scripts/README.md).

## Требования к окружению

- **PHP** >= 8.3 с расширениями: `mbstring`, `xml`, `pdo`, `pdo_mysql`, `bcmath`,
  `curl`, `zip` (для Excel-экспорта), `gd`/`imagick` (опционально).
- **Composer** >= 2.7
- **Node.js** >= 18 (тестировалось на 22) и **npm**
- **MySQL** >= 8.0 / **MariaDB** >= 10.4
- **Python** >= 3.10 (для парсера) с `pymysql`, `requests`
